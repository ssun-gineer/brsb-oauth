Privacy Policy

BRSB Local Runtime
Last updated: October 9, 2026

1. Overview

BRSB Local Runtime is a private, non-commercial research environment management tool operated by a single individual.

It is not offered as a public service. This policy describes its use of Google Drive data and related local operations.

2. Google Drive Access

BRSB Local Runtime uses Google OAuth 2.0 authorization with the drive.file scope.

This permission allows the application to access Google Drive files that it creates or that are made accessible to it through an authorized workflow.

3. Use of Data

Authorized Google Drive data is used for personal research file management, file transfers, integrity verification, and recovery operations.

These operations are initiated and controlled by the individual operator.

4. Data Storage

Files managed by the application may be stored on the operator's local computers or in the operator's Google Drive account.

OAuth credentials are maintained in the operator's local environment and are not published on this website.

Data is retained according to the operator's file management and recovery requirements.

5. Data Sharing

The application is not designed to sell Google user data or provide it to advertisers.

File transfers occur between the operator's local environment and Google Drive through Google's authorized services.

6. Access Revocation and Deletion

The operator can revoke the application's Google account access through Google Account settings.

Revoking access prevents further authorized API access but does not automatically delete existing local or Google Drive file copies.

The operator manages the deletion of retained files and local credentials separately.
